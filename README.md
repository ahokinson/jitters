# jitters

TUI for AI coding assistant usage metrics.

## Philosophy

Your machine, your metrics. Zero configuration - discover existing Claude Code and OpenCode data automatically. See usage patterns to make the most of your subscriptions.

## Prerequisites

- [Bun](https://bun.sh)
- [Task](https://taskfile.dev)

## Install

```bash
task install
```

Builds the binary and symlinks it to `/usr/local/bin/jitters`.
